# 3body-problem
An analysis of the 3 body problem using the orbit of Tatooine around its two suns

Techniques I have used:
- equations of motion
- kepler orbit equations
- solve_ivp
- cartesian co-ordinates
- two-body equations
- sci.integrate
- Axes3D
